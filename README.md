# Soham Sandbhor — Portfolio

A responsive, single-page developer portfolio inspired by the editorial structure and concise storytelling of the supplied reference site. It is an original implementation, not a pixel-for-pixel copy.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server.

## Before publishing

1. Replace `YOUR_EMAIL@example.com` in `index.html` with the public email address you want displayed.
2. Replace the LinkedIn and GitHub placeholder destinations with your exact profile URLs.
3. Add verified repository/demo links and project screenshots when ready.
4. Confirm the internship title/date and current status before public release.
5. Review project descriptions and update their status as the work progresses.

## Files

- `index.html` — page structure and portfolio content
- `styles.css` — responsive visual design
- `script.js` — small progressive enhancement
- `assets/soham-profile.jpg` — supplied profile photograph

No build step or framework is required.
